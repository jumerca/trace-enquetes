# DOMAINES & TERROIRS — Kit Claude Code

## Contenu
- `CONCEPT_ET_V01.md` : vision complète du jeu et périmètre V0.1.
- `PROMPT_CLAUDE_CODE.md` : instructions d'implémentation prêtes à fournir à Claude Code.
- `references_visuelles/01_panorama_domaine_vivant.png` : inspiration panorama, découpage des zones de jeu.
- `references_visuelles/02_village_artisanat_tourisme.png` : inspiration architecture, métiers et visiteurs.
- `references_visuelles/03_couverture_et_territoire.png` : inspiration couverture/identité ; typographie illustrative à redessiner.

## Comment l'utiliser
1. Décompresser l'archive dans le répertoire du projet où Claude Code pourra accéder aux fichiers.
2. Ouvrir Claude Code dans ce répertoire.
3. Lui demander de suivre `PROMPT_CLAUDE_CODE.md` avec les fichiers graphiques de `references_visuelles/`.
4. Vérifier d'abord une tranche jouable, avant de chercher à reproduire une carte immense.

## Important
Les PNG joints sont des **images de direction artistique**, non des spritesheets prêts à animer. Le moteur doit employer des assets isolés, originaux, cohérents et autorisés ; ne pas utiliser les panoramas comme carte interactive.
