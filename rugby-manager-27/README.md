# Rugby Manager 27 — V2.1 (JLG Creative)

Jeu de gestion de rugby à XV : 66 clubs, cinq compétitions, carrière sur plusieurs saisons et **moteur de match 2D multi-agents** (30 joueurs autonomes, ballon physique, rucks, mêlées, touches et mauls disputés).

- Jouer hors connexion : `dist/Rugby_Manager_27_V2_0.html (V2.1)`
- Version installable (HTTPS) : `index.html` de ce dossier, ou `dist/PWA/` — voir `PUBLICATION_HTTPS.md`
- Changements : `RAPPORT_MODIFICATIONS_V2_0.md` · Tests et limites : `RAPPORT_TESTS_ET_LIMITES.md`
- Captures et séquence animée réelle : `tests/captures/`
- Construire : `python3 tools/build.py` (Python 3, aucune dépendance)

La V1.6 d'origine est conservée telle quelle dans `archive/`.
